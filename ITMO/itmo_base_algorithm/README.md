# ITMO: Algorithm (base)
The course on algorithms and data structures provides the foundation for writing efficient code: it examines classical algorithms (sorting, searching, graph traversal) and evaluates their time and space complexity.
It covers key structures — arrays, lists, trees, hash tables, heaps, and graphs — and teaches how to choose the most suitable one for a given task.
The practice is based on solving typical problems, including those similar to those given during technical interviews at IT companies.
